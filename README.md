# 🎉 Party 夾錢計算器 (Party Splitter)

一個專為聚會、飯局、活動設計的**輕量級、行動優先、單一檔案 (Single-file) 夾錢分帳 Web App**。無需安裝任何 App 或後端伺服器，直接透過 GitHub Pages 即可隨開隨用！

🌐 **線上預覽**：[https://terry47.github.io/party-splitter/](https://terry47.github.io/party-splitter/)

---

## ✨ 核心特色 (Features)

1. **📱 極致輕量與行動優先**：採用純前端 HTML/JS 實作，單一 `index.html` 搞定。載入極快，且針對手機瀏覽器進行 CSS Grid 網格佈局優化，完美適應窄螢幕。
2. **🆔 ID 驅動的成員管理**：突破傳統名字綁定的限制。成員中途改名或重新排序時，系統會自動透過唯一 ID 追蹤關聯，絕不會造成帳目錯亂。
3. **📁 多聚會歷史存檔**：支援在同一個瀏覽器內管理多個不同的 Party 紀錄，隨時切換、新增或刪除歷史帳目。
4. **🌐 繁體中文 / 英文雙語切換 (v3.0+)**：支援一鍵切換介面語系，方便跨國或外籍朋友共同參與。
5. **📤 極簡智慧 JSON 協作與備份 (v2.8+)**：
   * **單一聚會匯出/匯入**：可將單一 Party 獨立打包成 JSON 傳給朋友。匯入時自動偵測，若遇同 ID 衝突會貼心詢問「覆蓋」或「存為副本」。
   * **全資料庫備份 (📦 匯出全部)**：一鍵打包整台手機裡所有的歷史聚會，支援整包還原。
6. **🔍 個人消費明細 Break Down (v3.1+)**：點擊結算表格右側的查閱按鈕，即可隨時檢視每位成員的代付項目與分攤細節，對帳超透明。
7. **🎯 靈活的過數方案 (v2.3+)**：
   * **⚡ 最簡過數模式**：自動計算淨額並互相抵銷，以最少轉帳次數完成結算。
   * **🎯 大掌櫃集中收支模式**：指定一位大掌櫃統一收齊所有人的款項，再轉給實際代付者。
8. **📋 WhatsApp 一鍵匯報**：一鍵將「總消費」、「個人明細表」、「過數方案」與「收款資料 (FPS/PayMe)」排版成清晰的 WhatsApp 訊息格式直接貼到群組。

---

## 🛠️ 技術架構 (Tech Stack)

* **前端**：HTML5, CSS3 (Modern Grid/Flexbox, CSS Variables), Vanilla JavaScript (ES6+)
* **儲存**：瀏覽器 `localStorage` (`party_splitter_db`)
* **部署**：GitHub Pages (Static Hosting)

---

## 🚀 本地開發與使用方式

1. 將本專案 Clone 或下載到本地。
2. 直接用瀏覽器打開 `index.html` 即可開始使用。
3. 若要部署更新，直接將修改後的 `index.html` 推送到 GitHub 主分支即可透過 GitHub Pages 自動更新。
